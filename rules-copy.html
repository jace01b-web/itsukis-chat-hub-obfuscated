Publish the ICH database rules

One tap copies the whole ruleset to your clipboard, so there is nothing to select by hand. Selecting ~100 KB of text manually on a phone is what produces the Unexpected EOF error — the paste gets cut off part-way and the editor blames whichever line the unfinished string started on.

Then

  1. Open the Firebase console

    Go to your project → Realtime Database → the Rules tab.

  2. Clear what's in the editor

    Tap inside it, select all, delete. The box must be completely empty before you paste.

  3. Paste

    Long-press → Paste. Give it a second; it's a big document.

  4. Check the first and last characters

    Scroll to the very top: it starts {. Scroll to the very bottom: it ends }. If the bottom ends mid-word, the paste was cut off — clear it and paste again.

  5. Publish

    Press Publish. Servers, per-channel voice and the status picker start working immediately; nobody has to sign out.

Still getting Unexpected EOF? It is not a syntax error — both files compile against a real Realtime Database rules parser before they ship. It means the clipboard didn't deliver the whole thing. Paste the verification check below, or do it from a computer with firebase deploy --only database.
