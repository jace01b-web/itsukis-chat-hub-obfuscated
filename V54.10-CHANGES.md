# v54.10

- MVP / owner image banners were invisible in the profile card: the style attribute closed early (`url("")`). Fixed.
- Every profile banner is now one 17:6 shape (Discord's); uploads are cropped to 680x240.
- High contrast no longer draws borders/outlines around messages and UI; it only brightens dim text.
- Saved login: the profile was wiped by `stopAll()` right after it loaded, so a reopen could show "Choose a username" over the sign-in page. The profile is now stored after the reset; boot also waits for a slow auth check and recovers if the profile arrives late.
- Friends / Message Requests pages start at the top instead of the bottom.
- A channel's (or role's) Send Messages / Attach Files permission now locks the composer and the send path.
- Dragging a server icon with a picture no longer also drags the image.
- Build label bumped to 2026-11-15.01. Run `BUILD_SECRET=... node tools/stamp-build.js 2026-11-15.01` to add its token, then `node build-single.js`.
